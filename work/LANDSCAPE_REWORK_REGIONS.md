# Ручные дополнительные биомы: реализация и проверки

Root владеет engine/core/landscape-regions.mjs, интеграцией atlas-landforms/atlas-biomes и tests/landscape-regions.test.mjs. Профиль/UI/schema нормализуют выбранный список; этот модуль не выбирает отсутствующие категории.

Порядок: исходная связная геометрия и климат → выбранные территории/рельеф/климат → орографические осадки → окончательный watershed/реки/озёра → основной биом территории/контексты/переходы → навигация. Возвращаемые labels — только внутренняя рабочая карта, не новый публичный JSON-field. Источники наполнения и формат сохранения не менялись.

Для каждого выбранного ID задаётся floor(dryArea*.32/selectionCount) клеток; суммарно <=32% исходной суши, основным меткам остаётся >=68%. При нулевой квоте ничего не распределяется. Minimax-распространение от географически подходящей точки в доступной связной компоненте создаёт одну связную территорию. Пригодность учитывает исходную относительную высоту, влажность/температуру, близость моря и плавное крупномасштабное поле; длина волны растёт с картой. Дополнительные горы поднимают рельеф, болота/луга/леса на высокогорной основе получают низкие территории; температура и влажность меняются вместе с высотой.

Внутреннее сглаживание было недостаточно на маленьких провинциях: они оставались крутыми остатками гор, и после slope-classification выбранный swamp исчезал целиком. Наблюдаемый case square/islands/mountains/50/seed7/all6: все12 приблизительно соответствующих клеток превращались в cliffs/coast. Теперь рельефный переход продолжается также снаружи провинции на4–10 клеток основного профиля; внешние метки биома не меняются. Это сохраняет квоту labels и делает полноценную низину с плавными берегами. Граница цвета по-прежнему управляется отдельным transitionWidth.

Понижение территории в высокогорье без выхода также давало глубокое искусственное озеро вместо болота. От пониженной территории прокладывается сглаженная долина к морю/границе по ацикличному стоку исходного рельефа, не меняя двоичную геометрию суши. Окончательные flowTo/ранги/вода рассчитываются уже после долины; старые поля стока в проект не подставляются.

## Границы

68% — доля внутренних меток до воды/контекстов/navigation, не процент картинки. Маленькая или очень изрезанная суша может не вместить существенную территорию каждого из6биомов. Не гарантируется выбранный ID на любом математически допустимом вырожденном остатке. Вода/пляж/скалы/предгорья/снежные вершины — географические контексты; пойма больше не превращается в автоматически подобранный wetland. Флора/деревья/источники не создаются выбором лесного биома. Ручной editoroverride не запускает всю генерацию заново.
