Общие параметры

Настройки

Параметры оформления и управления хранятся в этом браузере. Карты сохраняются отдельно, по кнопке.

Данные и сохранение

Текущая работа всех вкладок автоматически перезаписывается в одном временном файле .run/working-session.json. После закрытия всех вкладок новое открытие начинает чистую сессию. Именованные проекты сохраняются по кнопке в папку projects/. Для переноса на другую машину экспортируйте проект JSON или скопируйте папку приложения целиком.

Сервер

По умолчанию: localhost:9670. Порт задаётся переменной PORT перед запуском. Установка пакетов не нужна. API доступен программно через JS/HTTP/CLI.
