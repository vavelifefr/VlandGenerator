# Источник сообщений MutationObserver

Итог диагностики: 2026-10-20. Установленный Codex 26.1013.3656.0. Отчёт: `evidence/browser-diagnostics.json`.

## Вывод

Сообщение `Failed to execute 'observe' on 'MutationObserver': parameter 1 is not of type 'Node'` воспроизводится встроенным браузером Codex на статическом iframe без JavaScript. Оно не принадлежит VlandGenerator. Изменения рабочего кода проекта или установленного приложения не выполнялись.

| Проверка в изолированной скрытой вкладке | Результат |
| --- | --- |
| Обычный статический HTML без скриптов и iframe, открытие и три обновления | 0 новых ошибок в 4 загрузках |
| Статический HTML с iframe, обе страницы без скриптов | Та же ошибка в 4 из 4 загрузок |
| Шесть редакторов VlandGenerator напрямую, генерация и переключение Карта/Контент, 1100 и 360 px | 12 случаев; предупреждений и ошибок в журнале нет |

Минимальные HTML, сообщения, время событий и данные проверок сохранены в отчёте. Они получены на отдельном HTTP-сервере и временной копии, без пользовательских проектов и корневой рабочей сессии. Пользовательская вкладка не использовалась.

## Механизм и точность атрибуции

В рабочих исходниках VlandGenerator нет MutationObserver. Canvas использует ResizeObserver — наблюдение за размером элемента, с другим API и текстом ошибки.

В установленном приложении прочитан служебный модуль `.vite/build/browser-page-preload.js` из `app.asar`. Он обслуживает аннотации и обход вложенных документов. Функция `ac` проверяет наличие документа iframe, но не наличие его корневого элемента. Вызываемая функция `Vb` подключает MutationObserver к `n.documentElement` без проверки на null.

Во время инициализации или смены страницы iframe документ уже может существовать, а его корневой элемент ещё отсутствовать. Передача null в observe даёт наблюдаемый TypeError. Это найденный в исходнике служебного модуля путь к такой ошибке, согласующийся с минимальным воспроизведением.

При этом браузерный инструмент отдаёт сообщение и время события, но не полный стек вызова. Принадлежность ошибки внешнему браузерному окружению подтверждена независимым воспроизведением; конкретный кадр runtime-стека функции Vb не получен. Эти два уровня доказательства не следует смешивать.

## Что исправлять

В VlandGenerator исправление не требуется. Исправление служебного preload должно находиться в самом приложении Codex: дождаться появления корневого элемента вложенного документа и корректно переподключать наблюдение при его смене. Установленная сборка не изменялась; исправление в какой-либо другой версии не проверено.

Не следует скрывать все ошибки консоли, подменять MutationObserver приложения или менять загрузку iframe проекта ради этого сообщения. Проверочные страницы продолжают сообщать реальные ошибки своих сценариев; исходные десять событий предыдущего аудита сохранены в истории и получили ссылку на уточнённую атрибуцию.
